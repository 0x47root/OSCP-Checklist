# Hash Cracking

- Identify hash: `hashid offsec.hash`
- Cracking with john: `john --wordlist=/usr/share/wordlists/rockyou.txt offsec.hash`
- Searching for specific hash: `hashcat -hh | grep -i 'blowfish'`
- Cracking with Hashcat: `hashcat -m 3200 hash /usr/share/wordlists/rockyou.txt --force`
  - Kerberos TGS-REP: `-m 13100`
- Search with hashes.com: https://hashes.com/en/decrypt
