# General Reminders
- Software version found> > Always Google for exploits
    - Also for local software (like exiftool)
- Take the time to actually read and understand the exploit and fix accordingly
- When finding names, try creating usernames, like: `<first_name>.<last_name>`
- When finding a large list of users, try password spraying with a common password, like: `<Season><Year>`
- Never forget to add hostnames to `/etc/hosts`, tools like impacket-mssqlclient may not work otherwise (if using Kerberos tickets)
